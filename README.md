# 📊 Assigned Studies — Python & Data Analytics

A collection of practical assignments, programming exercises, and data analysis case studies completed while learning Python and data analytics.

This repository focuses on solving real-world analytical problems using Python libraries, numerical computations, data manipulation, and SQL.

---

## 📚 Contents

### 1. NumPy Case Studies

Practical exercises covering array operations, statistical calculations, indexing, filtering, ranking, and conditional logic.

| Case Study                              | Description                                                                                          |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Employee Performance & Salary Analytics | Analyze quarterly employee performance, calculate averages, rank employees, and measure growth.      |
| Retail Sales Performance Analysis       | Compare store performance, calculate quarterly sales, rank stores, and identify above-average sales. |
| Student Performance Analytics           | Analyze student marks, calculate averages, determine pass/fail status, and assign grades.            |

**Concepts covered:**

* Array creation and manipulation
* Aggregation using `np.sum()`, `np.mean()`, and `np.max()`
* Indexing and slicing
* Boolean indexing and conditional filtering
* `np.where()` and `np.all()`
* Sorting and ranking using `np.argsort()`
* Axis-based operations
* Percentage calculations

### 2. SQL Case Studies

SQL assignments focused on querying datasets, analyzing business performance, and extracting meaningful insights from relational databases.

**Topics covered:**

* SELECT, WHERE, and ORDER BY
* Aggregate functions
* GROUP BY and HAVING
* INNER JOIN and OUTER JOIN concepts
* Subqueries and Common Table Expressions (CTEs)
* Window functions
* Business-oriented data analysis

### 3. Pandas & Data Analysis

Exercises focused on working with tabular datasets and performing exploratory data analysis using Pandas.

**Topics covered:**

* DataFrame and Series operations
* Dataset inspection and data types
* Missing-value and duplicate detection
* Data filtering and sorting
* Grouping and aggregation
* Statistical calculations
* Date and time analysis
* Data visualization and business insights

## 🚀 Getting Started

### Prerequisites

Install Python and the required libraries.

```bash
pip install numpy pandas matplotlib
```

For SQL case studies, install and configure MySQL if required by the project.

### Clone the Repository

```bash
git clone https://github.com/callmeAru/Assigned_studies.git
```

Navigate to the repository:

```bash
cd Assigned_studies
```

### Run the Notebooks

1. Open the repository in Jupyter Notebook or Google Colab.
2. Select the required notebook.
3. Execute the cells sequentially.
4. Review the outputs and analytical findings.

For Google Colab, upload the notebook or open it directly from GitHub.
